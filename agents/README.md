# AI Agents

| Agent | Odpovědnost | Výchozí oprávnění |
|---|---|---|
| Manager | Koordinace požadavků, plánů a workflow | Read-only + návrhy |
| Coder | Vývoj skriptů, integrací, testů a konfigurací | Práce v repozitáři |
| Auditor | Nezávislá kontrola bezpečnosti a změn | Read-only |
| Monitor | Metriky, health checks a události | Read-only |
| Operator (později) | Provedení schválených úloh | Úzce omezená oprávnění |

Agenti nejsou autoritou pro přidělování oprávnění. Přístup vynucují externí systémy.
