# Adapters

Adaptéry převádějí společné kontrakty z core/ na konkrétní nástroje a platformy.
- ai-clients/ – klientské instrukce pro GitHub Copilot a Kilo.
- proxmox-api/ – Proxmox VE API integrace.
- ssh/ – omezené SSH operace a vzdálená diagnostika.

Klientské adaptéry vycházejí ze společného AGENTS.md; nesmí vytvářet vlastní bezpečnostní pravidla.
