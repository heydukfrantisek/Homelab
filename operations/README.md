# Operations evidence

Interní provozní evidence, nikoli uživatelský návod.
- change-log/: schválené změny a jejich výsledek.
- incidents/: incidenty a poučení.
- inventory/: ověřená inventura; citlivé hodnoty redigovat.
- decisions/: technická rozhodnutí a jejich zdůvodnění.

Neukládat tajné údaje ani neanonymizované výpisy.
