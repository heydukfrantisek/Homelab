# Uživatelská dokumentace

Tato část je určena pro běžné používání a orientaci v ekosystému. Popisuje co systém obsahuje, jaké služby poskytuje, jak spolu souvisejí a jaký je jejich aktuální stav.

## Obsah
- overview.md – účel a přehled ekosystému.
- architecture.md – architektura a vztahy komponent.
- services.md – přehled spravovaných služeb.
- operations.md – běžné používání a provozní přehled.
- glossary.md – slovníček pojmů.

Tato uživatelská dokumentace neobsahuje instalační postupy ani instalační příkazy. Interní technické návrhy, API kontrakty a testovací postupy jsou vedené odděleně.
