# Přehled ekosystému

Ekosystém propojuje Proxmox infrastrukturu, monitoring a specializované AI agenty do jednotného a auditovatelného workflow.

## Hlavní schopnosti
- Přehled o stavu infrastruktury.
- Příprava a kontrola změn.
- Vývoj a údržba automatizací.
- Nezávislý bezpečnostní a provozní audit.
- Evidence rozhodnutí a změn.

Projekt je ve fázi návrhu základní struktury. Žádný agent ani monitoring není tímto commitem nasazen do Proxmoxu.
