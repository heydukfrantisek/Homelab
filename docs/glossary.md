# Slovníček

- Proxmox VE: platforma pro správu virtualizace a kontejnerů.
- CT: systémový kontejner spravovaný Proxmoxem.
- VM: plnohodnotný virtuální stroj.
- Adapter: integrační vrstva mezi společným jádrem a platformou.
- Workflow: řízený sled kroků od požadavku po ověření.
- Least privilege: přidělení pouze minimálních potřebných oprávnění.
- Dry-run: simulace změny bez jejího provedení.
- Audit trail: dohledatelný záznam rozhodnutí a akcí.
