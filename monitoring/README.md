# Monitoring

Cílové oblasti:
- Proxmox node: dostupnost, CPU, RAM, teploty a zatížení.
- Storage: kapacita, stav disků, SMART a chyby.
- CT/VM: stav, prostředky a dostupnost služeb.
- Síť: dostupnost, latence a klíčové síťové služby.
- Aplikace: health checks a závislosti.

Konkrétní stack (např. Prometheus/Grafana) zůstává otevřeným rozhodnutím. Žádné metriky ani prahy zatím nepovažujte za nakonfigurované.
